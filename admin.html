GitHub access

Publishing needs a GitHub fine-grained token for the SligoTown_Site_Models repository with Contents: read and write. GitHub › Settings › Developer settings › Fine-grained tokens.

The token stays in this browser and goes only to api.github.com. Without it, use Download config.json and upload the file to the repository yourself.
